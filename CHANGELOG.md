# Changelog

## 0.1.0

- Maintain community-neutral packs in YAML with fixed file URLs, SHA-512 hashes and client/server sides.
- Preserve vanilla-plus convenience, performance, voice and backup mods; provide a minimal performance pack.
- Build a bundled HMCL MRPACK, server ZIP and Docker image with one Python builder.
- Build and release on CNB, with optional GitHub code synchronization.
- Keep Makers RCON administration, status caching and the optional authentication proxy separate from Docker.
- Use Docker named volumes and explicit optional RCON configuration.
