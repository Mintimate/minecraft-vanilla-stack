01 / PREPARE YOUR CLIENT

客户端，几步就准备好。

Windows、macOS 与 Linux 都能使用独立游戏实例。

前往 CNB Releases ↗

  1. 准备启动器与账号

    安装 HMCL，登录拥有 Minecraft Java 版游玩资格的 Microsoft 账号。下载 HMCL ↗

  2. 下载与导入

    下载所选预设的 client-hmcl .mrpack，模组已内含。拖入 HMCL 创建独立实例，无需解压。

  3. 检查 Java 与内存

    默认套包使用 Java 25，可先分配 4 GiB 内存。首次安装需要联网，安装包不含游戏本体、Java 或账号。

  4. 添加自己的服务器

    由服主提供服务器地址，并将准确的 Java 玩家名添加到白名单。玩家名与登录邮箱不同。

02 / START YOUR SERVER

给世界一个家。

下载部署文件，配置环境，启动 Docker Compose。

Docker 部署指南 →

  1. 取得部署文件

    从对应版本标签的源码取得 compose.yaml、docker/.env.example 和 manage.sh。Release 的 Docker-images.txt 提供每套包的镜像摘要。

  2. 配置环境与 EULA

    复制环境文件为 .env，设置 MC_IMAGE 为所选包的镜像摘要，按主机资源调整内存。阅读并自行同意 Minecraft EULA 后，将 EULA=false 改为 EULA=true。

  3. 启动与开放游戏端口

    等待日志出现 Done。在防火墙／安全组放行游戏 25565/TCP，使用语音时放行 24454/UDP。

  4. 添加白名单与邀请朋友

    执行 ./manage.sh whitelist 进入控制台，输入 whitelist add PlayerName。将地址与对应客户端发给朋友。

仓库目录 / shell
cp docker/.env.example .env
# 阅读 EULA，设置 MC_IMAGE 与内存
chmod +x manage.sh
docker compose pull
docker compose up -d
docker compose logs -f minecraft

Ctrl+C 退出日志跟踪，不会停服。命名卷保存世界与自动备份；定期执行 ./manage.sh backup 创建停服备份。
